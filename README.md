# Vademecum Tipologia B e C — Prima Prova

App didattica interattiva (singolo file HTML, nessuna dipendenza da installare) per la preparazione alla Prima Prova dell'Esame di Stato, pensata per classi quinte di liceo linguistico (livello medio-basso).

## Contenuti

- **Guida**: struttura della prova, differenze tra Tipologia B e C, metodo in 7 passi, criteri di valutazione, gestione del tempo
- **Prove 2023, 2024, 2025, 2026**: tutte le tracce di Tipologia B (B1, B2, B3) e C (C1, C2) — 20 tracce
  - sintesi della traccia con fonte istituzionale
  - domande di comprensione
  - svolgimento modello (elaborato originale a scopo didattico)
  - commento tecnico
  - quiz finale di 5 domande con correzione automatica
- **Checklist** finale ed errori più comuni

## Nota sulle fonti

I testi integrali delle tracce sono pubblicati dal Ministero dell'Istruzione e del Merito (istruzione.it → Esame di Stato → Tracce ed esempi). Poiché contengono estratti di opere protette da diritto d'autore, l'app ne riporta solo una sintesi con autore, titolo e fonte. Gli svolgimenti sono elaborati originali.

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository su GitHub (es. `vademecum-tipologia-b-c`).
2. Carica i file `index.html`, `README.md` e `.nojekyll` nella radice del repository.
3. Vai in **Settings → Pages**.
4. In *Build and deployment* scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`, poi **Save**.
5. Dopo circa un minuto l'app sarà online su `https://<tuo-utente>.github.io/<nome-repository>/`.

## Uso in locale

Basta aprire `index.html` in un browser. I font (Google Fonts) richiedono connessione; senza rete l'app funziona comunque con font di ripiego.
